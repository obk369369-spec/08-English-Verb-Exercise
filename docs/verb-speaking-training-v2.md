# 8번 영어 동사 자동화 말하기 훈련 규칙 v2 (2026-10-25)

## 목표
A1 초등학생 수준의 짧고 쉬운 영어로, 동사 하나를 다양한 문장 구조에서 한국어 번역 없이 즉시 말한다. 질문은 영어로만 짧게 제시한다. 설명과 피드백은 필요할 때 한국어로 제공한다.

## 훈련 순서
1. 한 동사를 고른다(help 기본). 정형화된 질문-답변만 반복하지 않는다.
2. 자유 발화: 틀려도 중단하지 않고 5~10문장을 연속 발화한다. 중간 교정은 원칙적으로 보류한다.
3. 형태 전환: 순서를 섞어 현재, 과거, 미래, 현재진행, 과거진행, 현재완료, 과거완료, 미래완료, 부정문, 의문문, 수동태, can/could/should/would/must, 동명사, to부정사, 조건문, 구동사(help out/help with) 등을 상황에 맞게 발화한다. 문법적으로 자연스럽지 않은 조합은 강요하지 않는다.
4. 피드백: 발화 후 핵심 오류 2~3개를 고쳐 주고 사용자가 정확한 문장을 다시 말하게 한다.
5. 속도 훈련: 이미 익힌 표현을 순서를 바꾸어 짧은 신호에 즉시 말한다. 정확도보다 속도만 높이도록 압박하지 않는다.
6. 간격 복습: 다음 날, 3일 후, 7일 후 같은 동사를 다른 상황에서 재시험한다.
7. 각 세션의 동사, 목표 형태, 발화 문장, 오류 유형, 교정 결과, 응답 지연, 복습 예정일을 기록한다. 음성 인식이 제공되지 않으면 발화 속도·정확도 자동 측정을 주장하지 않는다.

## help 예시 전환
I help my friend. / I helped my friend. / I am helping my friend. / I was helping my friend. / I have helped my friend. / I will help my friend. / I can help my friend. / I don't help him every day. / Did you help her? / I want to help out. / Can you help me with this?

## 운영 원칙
기존 index.html과 기존 데이터는 삭제·덮어쓰기 금지. GitHub 정본과 변경 이력 보존. 규칙 문서 반영과 웹 UI 실제 구현 및 E2E 검증은 별개 단계이며, 테스트 증거 없이 전체 완료라고 선언하지 않는다. 사용자 수동 복사·붙여넣기나 중간 테스트를 기본 전제로 하지 않는다.
